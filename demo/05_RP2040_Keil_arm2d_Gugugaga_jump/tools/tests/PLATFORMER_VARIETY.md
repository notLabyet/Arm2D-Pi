# 路线结构变化（2026-09-10）

原后续路段仅四套模板，其中三套平台前段都是近似的两级登高，且只有整体位置随机。
本次改为八套模板、六种结构家族：单平台、两级登高、升降三平台、滑翔串、三级阶梯、
分离低平台。两个单平台模板、两个两级登高模板分别归为同一家族。

前三个教学路段保持固定，后续选择排除最近两段出现过的家族。滑翔模板权重为 2，
其他模板为 1。4096 段检查中滑翔出现 816 次（约 20%），不是固定周期插入。

每套模板使用三档水平伸缩 92%/100%/108% 和整体降低 0/4/8 px，合计 72 种几何组合。
平台宽度、位置和曲奇横坐标同步伸缩，曲奇仍为 24x24；平台和曲奇高度同步降低。
不独立随机抛撒曲奇，以保留可达的收集路线。最高平台仍不超过 72 px。
普通段间距 480–640 px，滑翔段 720–880 px，均以 32 px 为一档。

新增长平台、三级阶梯、分离低平台，并将两处末端奖励靠近落脚区。
空位不足时仍整段延后，随机状态和路线历史不会提前消耗。固定 16 槽对象池不变。

- 20 分钟模拟 353 段，17 次坐标重置；普通跳跃策略 1403 枚，纯行走 0 枚。
  对象池峰值 16/16，可见峰值 7；生成持续向前。

- 主机状态大小仍为 252 字节，新增两个历史字段利用原结构尾部填充。
